This project is a scalable authentication and CRUD API built using Node.js, Express, and MongoDB. 
It allows users to register, login, and perform CRUD operations securely using JWT authentication.

Features:
- User Registration
- User Login with JWT Authentication
- Create, Read, Update, Delete APIs
- MongoDB Database Integration
- Secure Password Hashing using bcrypt

- Tech Stack Used
- Node.js
Express.js
MongoDB
JWT Authentication
Bcrypt

Run Instructions
npm install
npm start
